# ⚙️ Performance Marketing & Pipeline Calculators

A collection of open-source, client-side marketing calculators and utilities designed to help media buyers, founders, and growth marketers move away from vanity metrics and optimize for true unit economics.

### 🧰 The Tool Suite (Live Links)

All calculators are hosted live and are free to use with no email gating or logins required:

1. **[Break-Even ROAS Calculator](https://davidtamachi.ca/break-even-roas-calculator.html)**: Factor in COGS and gateway fees to find your true e-commerce profit margins.
2. **[Target CPA Baseline Calculator](https://davidtamachi.ca/target-cpa-baseline-calculator.html)**: Work backward from your win rates to set strict Google Ads Smart Bidding guardrails.
3. **[KPI Metric Calculator](https://davidtamachi.ca/kpi-metric-calculator.html)**: Universal math for traffic, conversion rates, and pipeline velocity.
4. **[UTM Link Builder](https://davidtamachi.ca/utm-link-builder.html)**: Generate perfectly formatted, GA4-compliant campaign tracking URLs.
5. **[Google Ads RSA Previewer](https://davidtamachi.ca/rsa-previewer.html)**: Mockup and validate Responsive Search Ads before launching.

### Tech Stack
* Vanilla HTML5 / CSS3
* JavaScript (ES6) - 100% Client-side execution
* CSS Variables for native Dark Mode
